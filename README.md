# 민원 처리 결재 행정 시스템

## 1. 시스템 개요

### 목적
- 행정기관 내 민원 접수부터 처리, 결재, 결과 통보까지의 전체 과정을 전산화하여 업무 효율성을 높임.
- 결재 단계의 자동화 및 기록 관리로 행정 투명성을 강화함.

### 주요 기능
- **민원 접수 관리**: 온라인 접수, 자동 번호 부여, 담당자 배정
- **민원 처리 관리**: 민원 등록
- **결재 관리**: 문서 결재선 설정, 단계별 결재(기안 → 검토 → 승인)
- **알림 및 통보**: 결재 요청, 승인 결과
- **권한 관리**: 관리자, 담당자, 결재권자 등 역할 기반 접근 제어(RBAC)

### 시스템 구성
- **프론트엔드**: 민원 등록 및 진행 조회 UI, 결재 요청 및 승인 화면
- **백엔드**: Spring 
- **DBMS**: Oracle 기반 민원·결재 데이터 관리
- **인증/권한**: JWT 기반 로그인 및 역할별 권한 검증
- **통합 알림 모듈**: 이메일, SMS, 내부 알림 지원

---

## 2. 업무 흐름

### 1) 민원 접수 단계
1. 접수자가 시스템을 통해 민원 등록 (민원 유형, 내용 등 입력)
2. 시스템이 자동으로 **민원번호**를 생성하고 담당자에 배정

### 2) 민원 처리 단계
1. 담당자는 처리 진행사항, 첨부문서, 검토 의견 등을 입력
2. 처리 완료 시 결재 상신(기안)을 등록
3. 시스템은 해당 문서의 **결재선(결재 순서)** 을 조회하여 자동으로 결재 요청 전송

### 3) 결재 단계
1. 결재권자는 요청 문서를 검토 후 승인 또는 반려 처리
2. 결재 결과는 즉시 시스템에 반영되며, 다음 결재자 또는 민원 담당자에게 통보
3. 모든 결재 이력은 디비에 저장

### 4) 민원 완료 단계
1. 최종 결재가 완료되면 민원 상태가 “처리완료”로 변경
2. 민원인에게 결과 통보(문서 첨부 가능)
3. 처리 및 결재 내역은 기록 보관용으로 아카이브

---

## 3. 주요 역할별 권한

| 역할 | 주요 기능 | 비고 |
|------|------------|------|
| **담당자** | 민원 처리, 결재 상신, 상태 변경 | 담당 부서 기준 |
| **결재권자** | 결재 승인/반려, 의견 등록 | 단계별 결재자 구성 가능 |
| **관리자** | 권한 관리, 결재선 설정, 통계 조회 | 시스템 전체 관리 |

---

## 4. 기대 효과
- 업무 프로세스의 **표준화** 및 **자동화**
- 결재 지연 방지 및 처리 속도 향상
- 민원 진행 상황에 대한 **투명한 이력 관리**
- 문서 누락, 중복 결재 등의 오류 감소
